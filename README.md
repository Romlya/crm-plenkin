# CRM ПЛЕНКИН

Внутренняя CRM: канбан, сделки, смета, финансы, монтажники, склад.

## Исправление (02.11.2026)

На Vercel фронт грузил обрезанные `/js/app.full.*.js` → UI падал.
Сейчас: один бандл `app.bundle.js` + загрузчик `app.js`.

## Данные на Vercel

Хранение в `/tmp` — после cold start данные могут сброситься.
Для постоянного учёта: `node server/index.js` на сервере с диском, либо Экспорт/Импорт из Настроек.

## Запуск локально

```bash
cd crm-plenkin
node server/index.js
```
